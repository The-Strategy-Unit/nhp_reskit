# Calculate mean, median, p10 and p90 values from 256 projection model runs

Calculate mean, median, p10 and p90 values from 256 projection model
runs

## Usage

``` r
calculate_principal_stats(tbl, group_cols)
```

## Arguments

- tbl:

  A suitably prepared results data table

- group_cols:

  Set of variables to group by, varying slightly for different
  inputs/outputs

## Value

A table with baseline values and principal projection summary values
