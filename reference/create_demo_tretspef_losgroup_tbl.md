Function to create a "tretspef + LoS group" table with synthetic values
The table contains synthetic (randomly created) values for a selection
of PODs, tretspefs, LoS groups and measures, across 2 "sites", as if
created by 64 model runs

## Usage

``` r
create_demo_tretspef_losgroup_tbl(seed)
```

## Arguments

- seed:

  integer, for reproducibility of outputs, a seed value to be used
