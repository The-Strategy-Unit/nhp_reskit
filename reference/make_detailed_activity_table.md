Create a gt table with data from
[compile_detailed_activity_data](https://the-strategy-unit.github.io/nhp_reskit/reference/compile_detailed_activity_data.md)

## Usage

``` r
make_detailed_activity_table(detailed_activity_data, final_year)
```

## Arguments

- detailed_activity_data:

  A suitable tibble

- final_year:

  string. The horizon year eg "2042/43"

## Value

A gt table
