# Zero-row prototype for the [compile_detailed_activity_data](https://the-strategy-unit.github.io/nhp_reskit/reference/compile_detailed_activity_data.md) output

The column names and types here must match what
[compile_detailed_activity_data](https://the-strategy-unit.github.io/nhp_reskit/reference/compile_detailed_activity_data.md)
returns when rows are present

## Usage

``` r
proto_detailed_activity_data(aggregation)
```

## Arguments

- aggregation:

  character Either "tretspef" or "age_group"

## Value

A zero-row tibble
